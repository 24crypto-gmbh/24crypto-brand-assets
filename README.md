# 24crypto — Brand & Social Media Kit (v1 · July 2026)

Everything needed for social media marketing and video content. Open **preview.html** in a browser to see all assets at a glance.

## What's inside

```
logos/
  svg/    Master logos — infinitely scalable, use these in design tools
  png/    Transparent PNG exports (logos: 500–4000px wide, marks: 256–2048px)
social/
  profile-pictures/   Ready-to-upload avatars, named per platform
  covers/             Banner/cover images, named per platform with exact size
  templates/          Post/story/share-image templates (PNG + editable src-*.svg)
content/
  brand-guidelines.md        Colours, logo rules, typography, voice, compliance
  brand-guide-pdf-src.html   Editable source of 24crypto-brand-guide.pdf
24crypto-brand-guide.pdf     One-page brand sheet for video/content editors
```

## Editing the templates

The `src-*.svg` files in `social/covers` and `social/templates` are plain SVG — open them in Figma, Illustrator or Canva (or any text editor), swap the headline text, export. Font: **Inter** (falls back to Helvetica). Colours and rules: see `content/brand-guidelines.md`.
